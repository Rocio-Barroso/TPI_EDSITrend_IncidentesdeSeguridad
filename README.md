# TPI_EDSITrend_IncidentesdeSeguridad
# Sistema de Gestión y Seguimiento de Incidentes de Seguridad

## Proyecto Integrador TPI – EDSI Trend

### 1. Descripción del proyecto

El proyecto consiste en proponer un sistema para gestionar y realizar el seguimiento de incidentes de seguridad en EDSI Trend. El objetivo es organizar la información de cada incidente, facilitar su asignación a un responsable y permitir el seguimiento de su estado hasta su resolución.

El sistema contempla el registro de incidentes, la definición de prioridades, la asignación de responsables y el registro de las acciones realizadas durante el seguimiento.

### 2. Objetivo

Mejorar la organización y el seguimiento de los incidentes de seguridad mediante un sistema que permita centralizar la información y consultar el estado de cada caso.

### 3. Funcionalidades principales

- Registrar incidentes de seguridad con su título, descripción y fecha de registro.
- Asociar cada incidente con un cliente.
- Definir la prioridad y el estado del incidente.
- Asignar un responsable para su atención.
- Registrar comentarios y acciones de seguimiento.
- Consultar la evolución de cada incidente hasta su resolución.
